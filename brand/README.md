# Büroflow Brand Assets v2

**Update:** Das B-Icon wurde vektorisiert — jetzt scharf bei jeder Größe.

## Logo

### Für dunkle Hintergründe

* `logo\\\_white\\\_transparent.svg` / `.png` — weißes Logo, transparent
* `logo\\\_on\\\_dark\\\_bg.png` — Logo auf #1A1D24 (für Social/Print)

### Für helle Hintergründe

* `logo\\\_dark\\\_transparent.svg` / `.png` — dunkles Logo (#1A1D24), transparent
* `logo\\\_on\\\_light\\\_bg.png` — Logo auf Weiß (für Social/Print)

## Nur Icon (B-Symbol)

* `icon\\\_only\\\_white.svg` — pure Vektor-SVG, weiß
* `icon\\\_only\\\_dark.svg` — pure Vektor-SVG, #1A1D24

## Favicon

* `favicon.ico` — Browser-Tab (16/32/48px multi-res)
* `favicon\\\_512.png` — PWA / iOS hochauflösend
* `favicon\\\_192.png` — Android Home Screen
* `favicon\\\_32.png` — Standard Browser-Tab
* `favicon\\\_white\\\_transparent.png` — für dunkle Themes
* `favicon\\\_dark\\\_transparent.png` — für helle Themes

## Brand-Farben

* **Primär dunkel**: `#1A1D24`
* **Primär weiß**: `#FFFFFF`
* **Akzent grün**: `#5DCAA5`

## HTML-Einbindung

```html
<link rel="icon" type="image/x-icon" href="/favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon\\\_32.png">
<link rel="icon" type="image/png" sizes="192x192" href="/favicon\\\_192.png">
<link rel="apple-touch-icon" sizes="512x512" href="/favicon\\\_512.png">
```
