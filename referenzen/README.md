# Motion-Referenzbibliothek

Von Rui freigegebene Komponenten, die das Zielniveau zeigen.
Der Regie-Bot liest sie mit `komponente_lesen` und überträgt die
Technik auf eigene Motive — sie sind Lehrmaterial, kein Baukasten.

Die Laufzeitkopien liegen in `vault/custom/` (nicht im Repo).
Bei Änderungen: dort bearbeiten, dann hierher kopieren.

| Komponente | Zweck |
|---|---|
| `aussage-pro` | Hook & CTA. Zeile fährt, Wörter materialisieren sich positionsabhängig |
| `marken-intro` | Intro: Logo rast herein mit Motion Blur, Text-Reveal per Maske |
| `logo-outro` | Outro: gleiche Bewegung, ruhiger Ausklang |
| `infografik-pro` | Zahlen: hochzählen, Balken, Vorher/Nachher-Vergleich, Ring |
| `reveal` | Echtes Büroflow-Dashboard mit Kamerafahrt |
| `mahnflow-motion` | Echtes Mahnflow mit Cursor-Interaktion und Listen-Verdrängung |
| `ui-motion-pro` | UI/UX-Techniken: Cursor, Button-Zustände, Tippen, Toast, Skeleton |
| `motion-referenz` | Kamerafahrt über Stationen, Parallax-Ebenen, Morph-Übergänge |
| `dashboard-hero` | 1:1-Nachbau des Dashboards aus dem Büroflow-Repo |
| `dashboard-video` | Wie oben, mit gestreckten Timings für Video-Einsatz |
